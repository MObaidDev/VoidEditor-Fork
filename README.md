# Obsidian Editor

Obsidian Editor is a code editor based on the open-source Void Editor codebase.

Use AI agents on your codebase, checkpoint and visualize changes, and bring any model or host locally. Obsidian Editor sends messages directly to providers without retaining your data.

This repo contains the full source code for Obsidian Editor's Desktop app. If you're new, welcome!

- 🧭 [Website](https://voideditor.com)

- 🚙 [Roadmap](https://github.com/orgs/voideditor/projects/2)
